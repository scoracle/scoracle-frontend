# v2 card lift — single inset stroke, lighter tarot, paper-on-desk shadow

**Date:** 2026-05-09
**Scope:** Iteration on the chrome polish from earlier today. The double inset stroke + larger corner dots was the wrong fix — it added visual complexity to mask the actual problem, which was *cards don't visually lift off the page surround*. This pass drops the second stroke, lightens the tarot ornament so it stays subtle, and adds a subtle two-layer paper-on-desk shadow so cards genuinely float above the page.

## Goal

User feedback after `2026-05-09_v2-chrome-polish`:

> This isn't the fix. This is relying on the double bar to make the card stand out. Let's go back to the more minimal single line approach.
> 1. Make the tarot elements a lighter color
> 2. Let's increase the distinction between the MetaShell and ContentShell and the page background. Maybe some shadowing to make it pop off the page more?

The principle named here is important: *separate the page-vs-card distinction from the tarot ornament*. The tarot stroke and dots should be subtle and ornamental — they identify the card as a Scoracle card. The page-vs-card separation should be carried by **shadow**, which is the natural visual idiom for "this thing floats above the page."

The earlier double-stroke approach conflated the two — it made the ornament louder to compensate for missing card lift. Wrong move.

## What Was Done

### 1. Reverted to single inset stroke

Dropped `.card::after` (the second parallel stroke at `inset: 10px`). `.card::before` (single hairline at `inset: 6px`) returns as the only inset stroke. The "tarot card double border" is no longer the brand silhouette — single hairline + corner dots is.

### 2. Lighter tarot ornament — `--text-secondary` → `--text-tertiary`

Both the inset stroke and the four corner dots switched from `var(--text-secondary)` (Warm slate `#5A5046`) to `var(--text-tertiary)` (Soft sand `#8A7A5C`). Visibly softer — the stroke reads as ornament, not as a strong frame, and the dots feel like delicate corner marks rather than visual punctuation. The tarot character is still present at this lightness; it just stops competing with content.

### 3. Paper-on-desk shadow on Cards — softens the original "no drop shadows" rule

Two-layer Smoke-tinted shadow at low opacity:

```css
box-shadow:
  0 1px 2px rgba(35, 32, 32, 0.06),   /* tight close shadow — defines edge */
  0 4px 12px rgba(35, 32, 32, 0.04);  /* soft wider shadow — ambient lift */
```

This is intentionally **not** a SaaS drop shadow — both layers are very low opacity, neither has lift-on-hover growth, and the offsets are small. Combined effect: cards read as small paper artifacts sitting slightly above the page surround. Page-vs-card distinction is now carried by perceived elevation, not by tonal contrast or border weight.

The original v2 brief banned drop shadows outright. That was an over-correction in reaction to SaaS soft chrome. Refined the rule in [[Aesthetic Vision]] and `project_aesthetic_v2.md` memory: subtle paper-on-desk shadows on Cards are OK; saturated/colored/glowing/lift-on-hover/animated shadows are still out.

### 4. ProfileCard padding reduced — only one stroke now

`.profile-card` `padding: 14px` → `10px`. Math: single inset stroke at `6px` + 3px breathing room between stroke and content + 1px buffer = `10px`. Mode toggle and inner sub-tabs still sit cleanly inside the inset stroke.

## Verification

Browser-side smoke after dev reload:
- Cards visibly float above the page surround — paper-on-desk lift is clearly readable without feeling SaaS-y.
- Inset stroke and corner dots are present but subtle — they read as ornament, not as a heavy frame.
- ProfileCard's mode toggle and inner sub-tabs still cleanly contained within the inset stroke.
- Page-vs-card distinction now comes from shadow lift, not from forced color contrast or visual complexity.

## Result

The v2 card silhouette settles into its final form (for now): Bone surface, single hairline Soft-sand inset stroke, four 3px Soft-sand corner dots, two-layer subtle Smoke shadow for paper-on-desk lift, sharp edges. The tarot identity is delicate; the visual weight is in the lift.

This now matches the *elegance through simplicity* and *content is the driver* pillars — chrome stays out of the way, content does the talking.

## Implications + carry-forwards

- **The shadow rule update is the meaningful brand change here.** [[Aesthetic Vision]] now documents that subtle paper-on-desk shadows on Cards are part of the visual identity. When the eventual `<Card>` Solid primitive ships (Phase 3), it should render the same shadow values — they're the contract. Don't invent per-component shadows.
- **Shadows are a Card-only privilege.** Inputs, buttons, tab buttons, mode toggles do *not* get shadows. The shadow is the signal "this is the card-as-artifact" — applying it elsewhere dilutes that.
- **Soft sand (`--text-tertiary`) is now the canonical "card chrome" color** for the inset stroke and corner dots — softer than the Warm slate (`--text-secondary`) we tried in the previous iteration. If the dots need to be slightly more present in a future iteration, bump `--text-tertiary` slightly darker rather than reverting up the lightness chain.
- **The inset stroke could disappear entirely in a far-future iteration** if the corner dots + shadow + Bone-vs-page contrast prove sufficient. Not recommending it now — the stroke earns its keep as the tarot-frame signal — but flag for if minimalism keeps tightening.
