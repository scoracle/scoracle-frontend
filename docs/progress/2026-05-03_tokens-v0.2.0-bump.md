# 2026-05-03 — Bump @scoracle/tokens to v0.2.0

## Goal

Consume the new multi-target build of `@scoracle/tokens` (v0.2.0 — Style Dictionary scaffold landed earlier today; see `~/scoracleWiki/Progress/scoracle-tokens/2026-05-03_style-dictionary-scaffold.md`). v0.2.0 ships CSS, JS, and TS outputs from a single JSON source-of-truth, but drops the v0.1.0 root-level `tokens.css` export — consumers must update their import paths.

## What Was Done

- Updated the dependency pin: `package.json` `"@scoracle/tokens": "^0.1.0"` → `"^0.2.0"`.
- Updated the single import in `src/global.css`: `@import "@scoracle/tokens/tokens.css"` → `@import "@scoracle/tokens/css"`.
- Ran `npm install` to refresh `package-lock.json` against v0.2.0.

This is the **lockstep follow-up** to the breaking change in `scoracle-tokens@0.2.0`. No behavioral or visual change is expected — every `--<name>` CSS variable from v0.1.0 is preserved in v0.2.0, including the legacy `--<name>-dark` aliases used by `src/routes/index.css` and `src/routes/profile.css` (`background-color: var(--bg-dark)`).

## Files Changed

- `package.json` — bumped `@scoracle/tokens` from `^0.1.0` to `^0.2.0`
- `package-lock.json` — refreshed by `npm install` (resolves to v0.2.0 on GitHub Packages)
- `src/global.css` — single-line import path update

## Verification

- `npm install` — clean, "changed 1 package" (just `@scoracle/tokens`)
- `node_modules/@scoracle/tokens/dist/{css,js,ts}/` all present
- `npm run typecheck` — passes (no output)
- `npm run build` — passes; 112 modules transformed; client + SSR bundles emitted; profile bundle holds at 86.69 KB / 25.53 KB gz (matches the post-cutover baseline)
- Spot-checked built CSS: `--bg-card`, `--font-display`, `--percentile-elite` all present in `entry-client`, `profile`, `legal`, `SearchBar` bundles — tokens are flowing through correctly
- **Not verified visually:** could not drive a browser from this session. Surface area is one CSS import line; build + typecheck both green; the `--<name>` and `--<name>-dark` token surface from v0.1.0 is preserved in v0.2.0 (additive only). Spot-check in the browser is recommended but low-risk.

## Result

`scoracle-frontend` is on `@scoracle/tokens@0.2.0`. The mobile pivot's first foundation-package consumer migration is done — Phase 0 step 1 (Style Dictionary multi-target build) is fully landed end-to-end (token build → publish → flagship consumption).

**Open follow-ups (not blocking):**
- The two `var(--bg-dark)` references in `src/routes/index.css:16` and `src/routes/profile.css:14` are the only consumers of legacy `-dark`-suffix aliases. If the design intent there is "always-dark background" (likely), they're fine as-is. If they should be theme-following, a separate pass can switch them to `var(--bg)` inside `.dark { ... }` and drop the legacy alias surface in a future minor of `@scoracle/tokens`.
